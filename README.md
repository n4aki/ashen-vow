# ASHEN VOW — 灰の誓い

## GitHub Pagesで公開

`.github/workflows/pages.yml` は `main` へのpush時に検証・配信用ファイル作成・Pagesへの公開を行います。GitHubリポジトリの Settings → Pages → Build and deployment → Source で **GitHub Actions** を選んでください。初回は Actions の「Publish game to GitHub Pages」から手動実行もできます。

配信用フォルダーは `node --preserve-symlinks --preserve-symlinks-main scripts/build-pages.cjs` で `dist/` に作成します。ゲーム本体と参照されている画像だけを含みます。相対パスで読み込むため、リポジトリ名付きのURLでも動作します。旧Sitesの公開用フォルダー・アーカイブ・生成プロンプトは配信に含めません。

## 第3ステージ：毒霧の沼地

王墓クリア後、商店で買い物をして沼地へ進みます。通貨・強化・補給品は引き継がれます。タイトルの「STAGE 03」から直接開始も可能です。全5ウェーブ、敵HPは聖堂の1.4倍です。

緑の魔法弾が命中した場所と、ボス「毒沼の巨躯 モルグ」の叩きつけで毒だまりが残ります。毒だまりは0.9秒の予告後に5秒間発生し、範囲内にいると6ダメージを受けます（通常の被ダメージ無敵時間・防具・護符が有効）。ボスには待機・歩行・叩きつけ・倒れる専用モーションがあります。

背景は `assets/venom-mire.png`、ボスは `assets/mirelord-motion.png`。生成プロンプトは `assets/MIRE_PROMPTS.md`、モーション確認は `tests/mirelord-preview.html`、戦闘表示確認は `tests/mire-preview.html` です。

参考画像の雰囲気をもとにした、ブラウザーで遊べるピクセルアートのアクションゲームです。

## 遊び方

`index.html` をブラウザーで開いて「聖堂に挑む」を押してください。インストール不要です。背景やゲーム本体はローカルファイルで動作します。外部フォントが利用できない場合は端末のフォントに切り替わります。

開発用プレビューは `npm start`、その後 `http://127.0.0.1:4173` を開きます。

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印キー |
| 攻撃方向 | 移動方向（停止中は最後の方向） |
| 斬撃（長押しで連続攻撃） | クリック / J |
| 無敵回避 | Space |
| 旋風斬り（待ち時間5秒） | E |
| 蒼炎の衝撃（待ち時間9秒、敵の弾を消去） | R |
| 回復薬（HP +85、3回） | Q |
| 一時停止・再開 | Esc |

斬撃は移動方向へ出ます。停止中は最後の移動方向を保ち、正面35度以内かつ剣の届く範囲の敵へ最大15度だけ補正します。足元の矢印が攻撃方向を示し、攻撃中はその一撃の方向を表示します。マウス位置は攻撃・回避の向きに影響せず、クリックはJと同じ攻撃操作です。タッチ端末では左のアナログスティックと右のスキルボタンを使用できます。スティックの倒し具合で速度を調節し、指を離すと停止します。移動と攻撃長押しを同時に操作できます。横画面を推奨します。

各ステージは5ウェーブです。聖堂の番人を倒すと商店を経由して第2ステージへ進め、王墓のアヌビスを倒すと再び商店へ入り、第3ステージの毒霧の沼地へ進みます。沼地クリア後も商店に入り、第4ステージの灼熱の鍛冶場へ進みます。鍛冶場のボスを倒すと全ステージクリアです。敵を倒すとコイン・収集用の結晶が落ち、近づくと回収します。撃破による自動成長はなく、商店で選んだパワーアップだけが能力を強化します。ウェーブ突破時にHPが25回復します。赤い攻撃予告から回避してください。

- `enemy-motion.js`：魔術師・重装騎士・ボスのモーション再生と攻撃タイミング
- `assets/temple.png`：このゲーム用に生成した遺跡背景
- `assets/characters.png`：剣士・骸骨・魔術師・騎士の透過スプライト
- `assets/hero-motion-v2.png`：主人公の16コマのモーション用スプライトシート

テスト：`npm test`

## 主人公のモーション

主人公は、待機・走り・斬撃・回避の4種類を各4コマで再生します。待機と走りはループし、斬撃と回避は操作ごとに1回再生します。主人公の左右の向きは移動方向に合わせて反転します。停止中と上下だけの移動中は、最後の左右の向きを保持します。剣の攻撃方向は上下・斜めを含む移動方向に合わせます。一時停止とヒットストップ中はアニメーションも止まり、回避の残像は発生した瞬間のポーズを保ちます。

`tests/animation-preview.html` で4種類を同時に確認できます。左右反転・一時停止・0.25倍/0.5倍再生に対応しています。使用した画像生成プロンプトは `assets/HERO_MOTION_PROMPTS.md` を参照してください。

## 骸骨のモーション

待機・歩行・斬撃・倒れる動きを各4コマで再生します。攻撃の予告0.42秒は振りかぶる2コマに対応し、3コマ目の振り下ろしでダメージを判定します。その後0.3秒の構え直しに入ります。倒れた骸骨は直ちに敵の残り数から外れ、骨が崩れるアニメーションを再生して消えます。撃破報酬は1回だけ付与されます。

`tests/skeleton-preview.html` で動きを比較できます。生成には内蔵の画像生成ツールを使用し、プロンプトを `assets/SKELETON_MOTION_PROMPT.md` に保存しています。

## 魔術師・騎士・ボスのモーション

待機・歩行・攻撃・倒れる動きを各4コマで再生します。魔術師は接近・後退中に歩き、0.85秒の詠唱を終えた3コマ目で魔法弾を放ちます。騎士とボスは0.95秒の振りかぶり後、3コマ目の叩きつけで範囲ダメージを与えます。攻撃後には構え直す動きが入り、撃破後は同じ敵の倒れるモーションを再生します。ボスは騎士の素材を大きく表示します。

`tests/other-enemies-preview.html` で魔術師・騎士・ボスを比較できます。内蔵画像生成ツールで作成した素材のプロンプトは `assets/OTHER_ENEMY_MOTION_PROMPTS.md` に記録しています。

背景とキャラクターは内蔵の画像生成ツールで作成。使用プロンプトは `assets/ART_PROMPT.md` に保存しています。キャラクターの移動・攻撃アニメーション、戦闘エフェクト、HUDはコードで描画しています。


## 第2ステージ：砂に沈んだ王墓

聖堂の5ウェーブをクリアすると自動で商店に入ります。買い物を済ませたら「次のステージへ」で王墓へ進めます。コイン・結晶を引き継ぎ、体力は全回復、回復薬は最低3個まで補充します。タイトル画面の「STAGE 02」から直接開始することもできます。死亡後は同じステージを初期状態から再挑戦します。

王墓も全5ウェーブです。砂岩と黄金の墓所背景、黄金色の兵士、蒼い三連魔法弾、専用モーションを持つアヌビスの守護者が登場します。敵HPは聖堂の1.2倍、中盤の敵編成も強化しています。背景は assets/necropolis.png、ボスの16コマの画像は assets/anubis-motion.png。内蔵 image_gen で生成し、最終プロンプトは assets/NECROPOLIS_PROMPTS.md に記録しています。


主人公の体力はハートで表示します（1個＝15 HP、最大12個）。ダメージに応じて中身が減り、回復すると戻ります。基本は全ステージとも最大12個です。「生命の器」を買うと14個になります。

レベル・経験値システムとMP消費はありません。旋風斬りは5秒、蒼炎の衝撃は9秒のクールダウンが終わると再び使えます。結晶は商店でスキル用ルーンや補給品と交換できます。


## ステージ間の商店

ステージ1をクリア → 商店 → ステージ2をクリア → 商店 → ステージ3をクリア → 商店 → ステージ4、という流れです（最終ステージ後はクリア画面）。ウェーブ間には入りません。商店は安全な休息場所で、体力は全回復、回復薬は最低3個まで無料補充。所持金ゼロでも購入せずに出発できます。

| 商品 | 価格 | 効果 | 在庫 |
|---|---|---|---|
| 回復薬 | 45コイン | 回復薬 +1 | 3 |
| 旅の補給袋 | 110コイン | 回復薬 +3 | 1 |
| 結晶の交換薬 | 結晶2個 | 回復薬 +1 | 2 |
| 守りの護符 | 結晶4個 | 被ダメージを2回半減（端数切り上げ） | 1 |

回復薬はQで使用。購入品・残金・護符の残り回数を次ステージに引き継ぎます。無敵中の接触では護符を消費しません。再挑戦では購入品と残金がリセットされます。レベル・経験値・MPはありません。

背景：assets/merchant-refuge.png。内蔵image_genで生成し、プロンプトは assets/SHOP_PROMPT.md に保存。tests/shop-preview.html は所持金200・結晶6の独立した表示確認用ページです。


## 選べるパワーアップ

商店の「コイン強化」「結晶強化」「補給」で商品を切り替えます。強化は各1回購入でき、複数を自由に組み合わせられます。効果は購入直後から次ステージへ引き継がれ、その冒険中は有効です。再挑戦・新規開始でリセットされます。経験値やレベル制はありません。

| 通貨 | 商品 | 価格 | 効果 |
|---|---|---|---|
| コイン | 研ぎ澄まされた刃 | 90 | 通常攻撃 +25% |
| コイン | 鉄織りの外套 | 100 | 被ダメージ10%軽減（端数切り上げ） |
| コイン | 疾風のブーツ | 80 | 通常移動速度 +15% |
| コイン | 生命の器 | 120 | 最大ハート +2、追加分も回復 |
| 結晶 | 嵐のルーン | 3 | 旋風斬りの範囲 +30% |
| 結晶 | 蒼炎のルーン | 4 | 蒼炎の衝撃：威力 +40%、範囲 +25% |
| 結晶 | 時のルーン | 4 | E・Rの待ち時間15%短縮（4.25秒／7.65秒） |
| 結晶 | 吸命のルーン | 5 | 撃破1体につきハート0.2個分回復 |

外套と護符を同時に使う場合、外套で軽減した後に護符で半減します。通常攻撃の強化はE・Rには乗らず、スキルはルーンで個別に強化します。回復薬と護符は「補給」から引き続き購入できます。



## 第4ステージ：灼熱の鍛冶場

沼地の後に商店を経由して進みます。強化・通貨・補給品を引き継ぎ、全5ウェーブに挑戦します。タイトルの STAGE 04 から直接開始できます。敵HPは聖堂の1.6倍です。

炎の魔術師は速度165の三連火球を放ちます。ボス「熔鉄の暴君 ヴァルカン」は専用の16コマモーションを持ち、叩きつけ後に3か所の火柱を予告します。火柱は1～1.4秒の予告後に一度だけ22ダメージを与えます。範囲外へ移動するか回避で避けられます。

素材：assets/infernal-forge.png、assets/forge-lord-motion.png。内蔵image_genの生成プロンプトは assets/FORGE_PROMPTS.md。表示確認は tests/forge-preview.html、モーション確認は tests/forgelord-preview.html。

鍛冶場の背景には、溶岩だまりの緩やかな明滅、滝の元の絵柄が下へ移動する流れ（2層を交互にフェードして継ぎ目を軽減）、控えめな火の粉をCanvasで重ねています。明るい溶岩部分のマスクを初回のみ生成し、戦闘エリアの床や建造物を保ったままアニメーションします。



王墓には砂の滝に沿う模様の流れと落下する砂粒、沼地には限定した水面の流れ・泡・排水口の滴りを追加。いずれも背景演出で、ダメージ判定はありません。

## ステージごとの移動範囲

4枚の背景それぞれの中央戦闘床に合わせた境界を使用します。主人公は足元半径9px、敵も足元の余白を確保し、壁・水辺・溶岩の手前で止まります。回避・ノックバックは4px以下の刻みで衝突を判定し、境界の飛び越えを防止します。敵の出現位置とミニマップも同じ境界を参照します。背景の外周の橋・階段はステージ外の装飾です。tests/boundaries-preview.html で背景と境界を比較できます。

## ウェーブの変化

敵数は各ウェーブの基準から−1～＋2体で変化します（全体で4～14体）。敵の種類も抽選し、魔術師・重装騎士は進行に応じた上限を設けています。最終ウェーブは必ずボス1体です。包囲・二方向の挟撃・三隊・横陣・散開の5陣形から直前と異なるものを選び、向きと出現地点も変えます。出現場所は各ステージの境界内で、主人公から190px以上・敵同士の間隔を確保します。ウェーブ開始時には陣形名と出現数を表示します。
